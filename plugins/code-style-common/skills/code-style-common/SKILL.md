# Shared coding conventions

Use this skill when writing, editing, or reviewing code.

1. Read [references/common.md](references/common.md) and follow it.
2. If a `code-style-<lang>` skill applies to the current files, read that pack next. Same-named rules in the language pack win.
3. Follow this pack for anything the language pack does not cover.
